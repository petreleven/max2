

# HTML Lessons Outline (10-Year-Old Students)

## 1. Introduction to HTML (Completed)

**Goal:** Understand what HTML is.

Topics covered:

* HTML stands for **HyperText Markup Language**
* HTML is used to **build the structure of websites**
* Browsers read HTML and show it as a webpage
* Simple analogy used: **HTML is like the skeleton of a body**

Example shown:

```html
<p>Hello world</p>
```

Students learned that:

* HTML uses **tags**
* Tags usually have **opening and closing tags**

Example explained:

```html
<p>Hello</p>
```

---

# 2. Basic HTML Elements (Completed)

Students practiced using basic elements:

### Paragraph

```html
<p>This is a paragraph</p>
```

### Headings

```html
<h1>Big title</h1>
<h2>Smaller title</h2>
```

Explained that:

* `h1` is biggest
* `h6` is smallest

### Button

```html
<button>Click Me</button>
```

### Input

```html
<input>
```

Used to explain:

* webpages can **receive information from users**

---

# 3. Inline Styling (Completed)

Students introduced to **changing appearance using `style=""`**

Explained simply as:

> style tells the browser how something should look.

Example used:

```html
<p style="color:red">Hello</p>
```

Properties covered:

### Text color

```html
<p style="color:blue">Blue text</p>
```

### Background color

```html
<p style="background:yellow">Yellow background</p>
```

Students experimented with colors.

---

# Current Student Skill Level

Students can currently:

* Create simple HTML elements
* Understand opening and closing tags
* Use paragraphs and headings
* Add buttons and inputs
* Change **text color**
* Change **background color**
* Use the `style=""` attribute

# Recommended Next Lessons (For Next Instructor)

## 4. Page Structure

Introduce the basic structure of a webpage.

Example:

```html
<html>
<head>
<title>My Page</title>
</head>

<body>

<h1>My Website</h1>
<p>Hello</p>

</body>
</html>
```

Explain:

* `html`
* `head`
* `body`

---

## 5. Images

Very exciting for kids.

```html
<img src="cat.jpg">
```

Explain:

* `src` = where the image is stored

---

## 6. Links

Allow students to create clickable things.

```html
<a href="https://google.com">Go to Google</a>
```

Explain:

* links take you to another page

---

## 7. Lists

Teach structure.

Unordered list:

```html
<ul>
<li>Apple</li>
<li>Banana</li>
<li>Mango</li>
</ul>
```

Ordered list:

```html
<ol>
<li>Step one</li>
<li>Step two</li>
</ol>
```

---

## 8. Simple Styling Practice

Continue with:

* `font-size`
* `border`
* `text-align`

Example:

```html
<p style="font-size:30px; text-align:center">
Hello
</p>
```
